# Practical 8: Data Visualization-I — Titanic Dataset Exploration and Fare Distribution

## What We Are Doing in This Practical

In this practical, we use the **Titanic dataset** and perform **Exploratory Data Analysis (EDA)** using visualization techniques.
Mainly, we:

* Explore patterns in Titanic data
* Analyze passenger information
* Plot histogram of ticket fares
* Understand data distribution using Seaborn visualization 

This practical is important because visualization helps us:

* understand datasets easily
* identify patterns
* detect outliers
* analyze distributions

# 1. What is Data Visualization?

## Definition

## Viva Answer

Visualization helps in:

* understanding large datasets
* identifying patterns and trends
* detecting anomalies

# 3. What is EDA (Exploratory Data Analysis)?

Most important viva topic.

EDA is the process of analyzing and summarizing datasets using statistics and visualization techniques before model building.

# 4. Goals of EDA

# 9. What is Histogram?

Most important topic.

## Definition

Histogram is a graph showing frequency distribution of continuous numerical data.

# 10. Purpose of Histogram

* identify skewness

# 13. What is Distribution?

## Definition

Distribution describes how data values are spread across dataset.

---

# 14. Skewed Distribution

Important viva topic.

## Definition

When data is not symmetrically distributed.

Titanic fare distribution is usually:

```text id="l5w2qq"
Positively skewed
```

because few passengers paid very high fares.

---

# 15. Positive Skewness

## Definition

Distribution with long tail on right side.

Characteristics:

```text id="bjlwm9"
Mean > Median
```

---

# 16. What is Frequency?

## Definition

Frequency represents number of observations within a particular interval.

---

# 17. What is KDE (Kernel Density Estimate)?

Mentioned in manual with histogram. 

## Definition

KDE is a smooth curve representing probability density of data.

---

# 18. Why KDE is Used?

## Viva Answer

To understand distribution smoothly instead of only bar intervals.

# 24. Difference Between Histogram and Bar Chart

| Histogram             | Bar Chart        |
| --------------------- | ---------------- |
| Continuous data       | Categorical data |
| Bars touch each other | Bars separated   |
| Shows distribution    | Shows comparison |
