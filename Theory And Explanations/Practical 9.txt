# 1. What is a Box Plot?

Most important viva topic.

## Definition

A box plot is a graphical representation used to display:

* distribution
* spread
* median
* quartiles
* outliers

of numerical data. 

---

# 2. Why Box Plot is Used?

## Viva Answer

Box plots help compare distributions and identify variability and outliers efficiently.

---

# 3. Components of Box Plot

Important viva point.

| Component | Meaning        |
| --------- | -------------- |
| Minimum   | Smallest value |
| Q1        | First quartile |
| Median    | Middle value   |
| Q3        | Third quartile |
| Maximum   | Largest value  |
| Outliers  | Extreme values |

---

# 4. Median in Box Plot

## Definition

The middle line inside the box represents median.

It divides data into two equal halves.

---

# 5. Interquartile Range (IQR)

## Definition

Difference between Q3 and Q1.

Formula:

IQR = Q_3 - Q_1

---

# 6. Why IQR is Important in Box Plot?

Because the box length represents spread of middle 50% of data.

---

# 7. Quartiles in Box Plot

| Quartile | Meaning        |
| -------- | -------------- |
| Q1       | 25% data below |
| Q2       | Median         |
| Q3       | 75% data below |

---

# 8. What are Whiskers?

## Definition

Lines extending from box showing spread outside quartiles.

---

# 9. Outliers in Box Plot

## Definition

Data points lying far away from normal range.

They appear as separate points outside whiskers.

---

# 10. Why Box Plot is Better Than Histogram Sometimes?

## Viva Answer

Because it provides:

* median
* spread
* quartiles
* outliers

all in a compact visualization.
