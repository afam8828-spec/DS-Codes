# 1. What is Classification?

## Definition

Classification is a supervised machine learning technique used to predict categorical outputs.

Examples:

* Spam / Not Spam
* Purchased / Not Purchased
* Disease / No Disease

---

# 2. Difference Between Regression and Classification

| Regression                 | Classification      |
| -------------------------- | ------------------- |
| Predicts continuous values | Predicts categories |
| Example: House price       | Example: Yes/No     |

---

# 3. What is Logistic Regression?

Most important viva topic.

## Definition

Logistic Regression is a supervised machine learning algorithm used for binary classification problems. 

---

# 4. Why “Regression” Name if it Performs Classification?

Because it uses a regression equation internally, but final output is converted into categories using probability.

---

# 5. Binary Classification

## Definition

Classification with only two possible outputs.

Example:

```text id="s3v2pz"
0 → Not Purchased
1 → Purchased
```

---

# 6. Sigmoid Function

Very important.

## Definition

Sigmoid function converts any value into probability between 0 and 1. 

Formula:

\sigma(z)=\frac{1}{1+e^{-z}}

---

# 7. Why Sigmoid Function is Used?

## Viva Answer

Because classification requires probability values between 0 and 1.

---

# 8. Decision Boundary

## Definition

A boundary separating different classes.

Example:

```text id="8p4d2p"
Purchased | Not Purchased
```

Logistic Regression tries to find best decision boundary.

# 12. What is Confusion Matrix?

Most important viva topic.

## Definition

A confusion matrix is a table used to evaluate classification model performance. 

---

# 13. Components of Confusion Matrix

| Term | Meaning                     |
| ---- | --------------------------- |
| TP   | Correct positive prediction |
| TN   | Correct negative prediction |
| FP   | Wrong positive prediction   |
| FN   | Wrong negative prediction   |

---

# 14. True Positive (TP)

Model correctly predicts positive class.

Example:

```text id="jpr7hm"
Actually Purchased → Predicted Purchased
```

---

# 15. True Negative (TN)

Model correctly predicts negative class.

---

# 16. False Positive (FP)

Model predicts positive incorrectly.

Also called:

```text id="b7l0yk"
Type-I Error
```

---

# 17. False Negative (FN)

Model predicts negative incorrectly.

Also called:

```text id="e7ejm8"
Type-II Error
```

---

# 18. Accuracy

Most common metric.

## Definition

Accuracy measures proportion of correct predictions.

Formula:

Accuracy = \frac{TP+TN}{TP+TN+FP+FN}

---

# 19. Precision

## Definition

Precision measures how many predicted positive cases are actually positive.

Formula:

Precision = \frac{TP}{TP+FP}

---

# 20. Recall (Sensitivity)

## Definition

Recall measures how many actual positive cases are correctly identified.

Formula:

Recall = \frac{TP}{TP+FN}

---

# 21. Error Rate

## Definition

Error rate measures proportion of incorrect predictions.

Formula:

Error\ Rate = \frac{FP+FN}{TP+TN+FP+FN}

---

# 22. Difference Between Precision and Recall

| Precision                      | Recall                      |
| ------------------------------ | --------------------------- |
| Focuses on predicted positives | Focuses on actual positives |
| Important when FP costly       | Important when FN costly    |
