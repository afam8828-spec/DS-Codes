---

# 1. What is a Feature?

Most important viva topic.

## Definition

A feature is an individual measurable property or characteristic of data.

Examples in Iris dataset:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

---

# 2. Types of Features

According to the practical, features are categorized by datatype. 

Main types:

* Numerical
* Categorical (Nominal)

---

# 3. Numerical Features

## Definition

Features containing measurable numeric values.

Example:

```text id="1n1yfy"
Petal Length = 5.2
```

---

# 4. Nominal Features

## Definition

Categorical features without any order.

Example:

```text id="v72m7r"
Flower species names
```

---

# 6. Why Visualization is Performed Here?

## Viva Answer

---

# 7. Histogram in Iris Dataset

Histograms are created for each feature. 

Purpose:

* understand distribution
* analyze spread
* observe skewness

---

# 8. What Histogram Shows?

A histogram shows:

* frequency distribution
* concentration of values
* shape of distribution

---

# 9. Feature Distribution

## Definition

Feature distribution describes how values of a feature are spread across dataset.

---

# 10. Symmetric Distribution

## Definition

Distribution where left and right sides are approximately equal.

Characteristics:

```text id="qv2v0j"
Mean ≈ Median
```

---

# 11. Skewed Distribution

## Definition

Asymmetrical distribution of data.

Types:

* Positive skew
* Negative skew

---

# 12. Positive Skew

Long tail on right side.

```text id="q7oqcl"
Few very large values
```

---

# 13. Negative Skew

Long tail on left side.

```text id="2m08w1"
Few very small values
```

---

# 14. Why Compare Distributions?

## Viva Answer

Comparing distributions helps understand variability and differences among features.

---

# 15. Box Plot in Iris Dataset

Box plots are used for each feature. 

Purpose:

* detect outliers
* compare spread
* analyze quartiles

---

# 16. Outlier Detection Using Box Plot

Very important topic.

Outliers appear:

```text id="f72dfn"
Outside whiskers
```

---

# 17. Why Outliers Matter?

## Viva Answer

Outliers can affect:

* statistical analysis
* machine learning models
* prediction accuracy

---

# 18. Variability in Features

## Definition

Variability indicates how much feature values differ from each other.

---

# 19. High vs Low Variability

| Variability | Meaning                |
| ----------- | ---------------------- |
| High        | Values widely spread   |
| Low         | Values closely grouped |

---

# 20. Comparing Histograms and Box Plots

| Histogram                     | Box Plot                     |
| ----------------------------- | ---------------------------- |
| Shows frequency distribution  | Shows statistical summary    |
| Better for distribution shape | Better for outlier detection |

---

# 21. Why Multiple Visualizations are Used?
