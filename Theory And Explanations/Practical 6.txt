---

# 1. What is Naïve Bayes?

Most important viva topic.

## Definition

Naïve Bayes is a probabilistic supervised machine learning algorithm based on Bayes’ Theorem. 

---

# 2. Why is it Called “Naïve”?

Because it assumes that all features are independent of each other.

Example:

```text id="9jl8yo"
Petal length is independent of petal width
```

This assumption is called the naïve assumption.

---

# 3. What is Probability?

## Definition

Probability measures the chance of occurrence of an event.

Range:

0 \leq P(E) \leq 1

Where:

* 0 → impossible event
* 1 → certain event

---

# 4. Bayes’ Theorem

# 5. Meaning of Bayes’ Theorem

It calculates probability of a class based on given features.

Example:

```text id="wwvg0w"
Probability that flower belongs to Setosa
based on petal and sepal measurements
```

---

# 6. Terms in Bayes’ Theorem

| Term | Meaning           |                       |
| ---- | ----------------- | --------------------- |
| P(C  | X)                | Posterior Probability |
| P(X  | C)                | Likelihood            |
| P(C) | Prior Probability |                       |
| P(X) | Evidence          |                       |

---

# 7. Prior Probability

## Definition

Initial probability of class before observing data.

Example:

```text id="sg9v4o"
Probability of flower being Setosa before seeing features
```

---

# 8. Posterior Probability

## Definition

Updated probability after observing features.

---

# 9. Likelihood

## Definition

Probability of observing features for a given class.

---

# 10. Evidence

## Definition

Total probability of observed data.

---

# 11. Naïve Assumption

Very important viva point.

## Definition

Naïve Bayes assumes all features are conditionally independent given the class label. 

---

# 12. Why Naïve Bayes Works Well Despite Simple Assumption?

## Viva Answer

Because many real-world problems approximately satisfy independence assumption, making Naïve Bayes simple and efficient.

---

# 13. What is Classification in Naïve Bayes?

The algorithm calculates probability for each class and selects the class with highest probability.

---

# 16. Gaussian Naïve Bayes

Important viva question.

## Definition

Gaussian Naïve Bayes is used when features are continuous numerical values.

The manual uses:

```text id="r14j4t"
GaussianNB
```



---

# 17. Why “Gaussian”?

Because it assumes data follows normal (Gaussian) distribution.

---

# 18. Why Feature Scaling is Not Necessary Here?

Important viva question.

## Answer

Naïve Bayes is probability-based and less sensitive to feature scale. 

---

# 19. Advantages of Naïve Bayes

## Viva Points

* Simple
* Fast
* Works well on small datasets
* Efficient for classification
* Requires less training data

---

# 20. Disadvantages of Naïve Bayes

## Viva Points

* Assumes feature independence
* Less accurate when features are highly correlated
* Can oversimplify complex relationships

---

# 21. Difference Between Logistic Regression and Naïve Bayes

| Logistic Regression      | Naïve Bayes                 |
| ------------------------ | --------------------------- |
| Discriminative model     | Probabilistic model         |
| Learns decision boundary | Uses Bayes theorem          |
| Requires scaling often   | Scaling usually unnecessary |
