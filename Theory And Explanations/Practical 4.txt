# 5. What is Regression?

Most important viva topic.

## Definition

Regression is a supervised learning technique used to predict continuous numerical values.

Examples:

* House price prediction
* Salary prediction
* Temperature forecasting

---

# 6. What is Linear Regression?

## Definition

Linear Regression is a statistical and machine learning algorithm used to model the linear relationship between independent variables and dependent variable. 

---

# 7. Simple Meaning of Linear Regression

It tries to fit a straight line through data points for prediction.

Example:

```text id="wz5d2e"
More rooms → Higher house price
```

# 15. Assumptions of Linear Regression

Very important.

---

## A) Linear Relationship

Features and target should have linear relationship.

---

## B) Independence

Observations should be independent.

---

## C) Normal Distribution of Errors

Residuals should be normally distributed.

---

## D) No Multicollinearity

Features should not be highly correlated with each other.

---

# 27. What are Residuals (Errors)?

## Definition

Difference between actual value and predicted value.

Formula:

Residual = Actual - Predicted

---

# 29. Mean Squared Error (MSE)

Most important viva topic.

## Definition

MSE measures average squared difference between actual and predicted values. 

---

# 30. MSE Formula

MSE = \frac{1}{n}\sum (y_i - \hat{y_i})^2

---

# 31. Interpretation of MSE

| MSE Value | Meaning          |
| --------- | ---------------- |
| Low       | Better model     |
| High      | Poor predictions |

---

# 32. Why Squaring is Used in MSE?

## Viva Answer

Squaring:

* removes negative signs
* penalizes large errors more strongly

---

# 33. What is R² Score?

Another very important topic.

## Definition

R² score measures how well the model explains variance in target variable. 

---

# 34. R² Formula

R^2 = 1 - \frac{SS_{res}}{SS_{tot}}

---

# 35. Interpretation of R²

| R² Value | Meaning     |
| -------- | ----------- |
| 1        | Perfect fit |
| 0        | Poor model  |

---

# 36. Difference Between MSE and R²

| MSE             | R²                       |
| --------------- | ------------------------ |
| Measures error  | Measures goodness of fit |
| Lower is better | Higher is better         |

---

# 37. What is Overfitting?

Very important viva question.

## Definition

Overfitting occurs when model learns training data too perfectly and fails on new data.

---

# 38. What is Underfitting?

## Definition

Underfitting occurs when model fails to learn important patterns from data.

---

# 39. Difference Between Overfitting and Underfitting

| Overfitting              | Underfitting             |
| ------------------------ | ------------------------ |
| High training accuracy   | Poor training accuracy   |
| Poor testing performance | Poor overall performance |
| Learns noise             | Learns too little        |
