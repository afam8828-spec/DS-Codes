# 1. What is Data Wrangling?

## Definition

Data Wrangling (also called Data Cleaning or Data Preprocessing) is the process of converting raw, unorganized, incomplete data into clean and usable data. 

## Simple Explanation

Real-world data is messy:

* Some values are missing
* Some columns contain wrong formats
* Some values are duplicated
* Some features are categorical
* Numerical values may have different ranges

So before analysis or machine learning, we clean and prepare the dataset.

---

# 2. Why Data Wrangling is Important?

## Viva Answer

Data wrangling is important because machine learning algorithms require clean and properly formatted data. Incorrect or missing data can reduce model accuracy and produce wrong predictions.

## Important Points

* Improves data quality
* Removes inconsistencies
* Helps in better analysis
* Improves ML model accuracy
* Reduces errors
* Makes dataset standardized

# 9. Missing Values

One of the most important viva topics.

## What are Missing Values?

Missing values are empty or unavailable values in dataset.

Example:

| Age |
| --- |
| 22  |
| NaN |
| 35  |

NaN = Not a Number

---

## How to Detect Missing Values?

```python
df.isnull().sum()
```

This returns total missing values column-wise. 

---

# 10. Why Missing Values are Problematic?

## Viva Points

* Reduce accuracy
* Cause training errors
* Create bias
* Disturb statistical calculations

---

# 11. Methods to Handle Missing Values

## A) Remove Rows

```python

```

Used when missing data is very small.

---

## B) Fill Missing Values

### Mean Imputation

```python

```

Used for numerical data.

---

### Median Imputation

Better when outliers exist.

---

### Mode Imputation

Used for categorical data.

# 14. What is Data Normalization?

Very important viva question.

## Definition

Normalization is the process of scaling numerical data into a fixed range, usually between 0 and 1.



---

# 15. Why Normalization is Needed?

## Viva Points

* Removes scale differences
* Improves ML performance
* Faster convergence
* Prevents domination of large values

---

# 16. Min-Max Normalization

Manual uses MinMaxScaler. 

Formula:

x' = \frac{x - x_{min}}{x_{max} - x_{min}}

## Output Range

Between 0 and 1.

---

# 17. What is Feature Scaling?

Feature scaling means bringing all numerical features to similar scale.

Example:

| Feature | Range           |
| ------- | --------------- |
| Age     | 1–80            |
| Salary  | 10,000–1,00,000 |

Without scaling, salary dominates model.

# 19. Encoding

Encoding converts categorical data into numerical form.

---

## A) Label Encoding

Example:

| Gender | Encoded |
| ------ | ------- |
| Male   | 0       |
| Female | 1       |

Manual uses:

```python
map({'male':0, 'female':1})
```



---

## B) One Hot Encoding

Used when categories have no order.

Example:

| Embarked |
| -------- |
| C        |
| Q        |
| S        |

Converted into:

| Embarked_C | Embarked_Q | Embarked_S |
| ---------- | ---------- | ---------- |
| 1          | 0          | 0          |

Manual uses:

```python
pd.get_dummies()
```



---

# 20. Difference Between Label Encoding and One-Hot Encoding

| Label Encoding            | One Hot Encoding          |
| ------------------------- | ------------------------- |
| Converts to single column | Creates multiple columns  |
| Suitable for binary data  | Suitable for nominal data |
| Can introduce order       | No order introduced       |
